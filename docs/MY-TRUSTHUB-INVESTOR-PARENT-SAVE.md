# My TrustHub — Investor parent Save: release gate and environment contract

Status: Investor side deployed, **parent sync OFF**. Nothing here is set in
production. Variable names only; no key material exists yet and none is
generated by this repository.

## Identity (locked)

| Field | Value |
| --- | --- |
| hub | `investor` |
| profile class | `official_firm` |
| identifier namespace | `sec.crd` |
| source identifier | exact numeric firm CRD |
| specialist entity id (native id) | `crd-<CRD>` |
| jurisdiction | `US` |
| canonical return path | `/firm/sec-crd-<CRD>` |

Never an identity: the firms row UUID, the firm name, the slug, an individual
adviser CRD, a branch, a notice filing, or a state-registration observation.

## Release gate (Investor Vercel project, Production scope)

| Variable | Meaning |
| --- | --- |
| `NEXT_PUBLIC_INVESTOR_PARENT_SAVE_ENABLED` | Master switch. Exactly `1` to enable. |
| `MTH_INVESTOR_PARENT_SAVE_MODE` | Exactly `production`. Any other value is off. |
| `NEXT_PUBLIC_INVESTOR_PARENT_SAVE_CANARY_SLUGS` | Exact profile slugs, comma separated. Non-empty = canary. Empty or absent = broad. |

| State | Configuration |
| --- | --- |
| OFF (today) | any of the first two absent or different |
| CANARY | enabled `1` + mode `production` + non-empty exact slug list |
| BROAD | enabled `1` + mode `production` + empty slug list |
| malformed | a list item that is not `sec-crd-<CRD>`, a repeated slug, an empty item between commas, or a mode/switch in any other spelling → OFF |

The `NEXT_PUBLIC_` values are bundled at build: **redeploy Investor after
changing the switch or the list.** The slug list limits exposure only; the
identity is always re-derived on the server from the exact firm CRD.

## Keys (names only)

Investor Vercel project:

| Variable | Use |
| --- | --- |
| `MY_TRUSTHUB_V23_INVESTOR_KEY_ID` | Key id of the Investor Ed25519 signing key. |
| `MY_TRUSTHUB_V23_INVESTOR_SIGNING_PRIVATE_KEY_PEM` | Investor signs staging calls to Ask. |
| `MY_TRUSTHUB_V23_ASK_KEY_ID` | Key id of Ask's Ed25519 key. |

| `MY_TRUSTHUB_V23_PARENT_ORIGIN` | Optional. If set it must equal `https://www.asktrusthub.com`, otherwise no parent client is built. |

Ask (later, not part of this repository):

| Variable | Use |
| --- | --- |
| `MY_TRUSTHUB_V23_INVESTOR_KEY_ID` | Same key id as above. |
| `MY_TRUSTHUB_V23_INVESTOR_VERIFY_PUBLIC_KEY_PEM` | Ask verifies Investor's staging calls. |

Without the signing key, staging answers `local_only / unsigned`. Without the
Ask verify key, `/api/my-trusthub/profile-save/source` answers 503.

## What is checked at runtime for every staged Save

Read from the production firms table under the profile page's own publication
rule, by exact CRD equality (`apps/web/src/lib/my-investor/publication-port.ts`):

1. the slug is exactly `sec-crd-<CRD>`;
2. exactly one published firm row carries that CRD;
3. that row's own slug is the same canonical slug;
4. the firm is not synthetic and every registration row classifies as an
   official SEC/IARD firm (a firm with no registration row, or a mixed set, is
   not `official_firm`);
5. the browser sent no CRD, return path, entity id or name that disagrees.

If the database read fails, or any check fails, the device Save stands and
parent staging is refused. **This read has not yet executed in production**
(the gate has never been open); the first canary request is its first run.

## Activation order (operator, after Ask support lands)

1. Ask: Investor verifier, binding resolver for `official_firm` / `sec.crd`, accepted bindings for the three canaries.
2. Generate the Investor key pair and exchange public keys; set the five Investor variables and the two Ask variables.
3. Set the three release-gate variables with the canary list; redeploy Investor.
4. Live proof on the three canaries; an unrelated firm must stay device-only.

Rollback: set `NEXT_PUBLIC_INVESTOR_PARENT_SAVE_ENABLED` to anything but `1`, or remove
`MTH_INVESTOR_PARENT_SAVE_MODE`, and redeploy.
