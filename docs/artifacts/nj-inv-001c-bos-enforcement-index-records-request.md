# NJ-INV-001C records request — Bureau enforcement document index

## Why

Official HTML Orders & Filed Complaints indexes on njconsumeraffairs.gov currently return an
Incapsula interstitial (`SOURCE_ACCESS_BLOCKED`). Direct `/Actions/` PDFs remain retrievable.
The 45-document NJ-INV-001 corpus plus later official PDFs is **partial 2002–2025**, not a
complete alphabetical library.

Do not bypass the WAF. Request the Bureau's existing electronic index.

## Request

A machine-readable index of Bureau enforcement documents for **1 January 2000 through the
current date**, or the earliest electronic period available.

Preferred format: CSV or XLSX of an **existing** document-management index.

Requested fields:

- order/document number
- docket/reference number
- document type
- document date
- effective date
- disposition/status
- respondent legal name
- respondent type
- CRD firm number
- CRD individual number
- SEC file number where maintained
- NJ registration/reference number where maintained
- civil penalty
- restitution
- disgorgement
- bar/suspension/revocation indicator
- public document filename
- public document URL
- superseded/amended relationship
- source update date

## Do not request

- investor identities
- complainant identities
- account numbers
- SSNs
- personal financial information
- protected investigative materials
- non-public examination workpapers
