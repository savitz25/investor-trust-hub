# NJ-INV-002 records request — public issuer / exemption / ISO filing metadata

## Finding

Official form PDFs and instructions are publicly downloadable for several filing classes
(NJBOS Form 1 private placement, SCOR/U-7, Form NF, crowdfunding investor certification
forms). No public machine-readable index of filed offerings, crowdfunding issuers, or
Internet Site Operators was located. HTML forms indexes are Incapsula-gated.

## Request

Machine-readable **PUBLIC** filing metadata for 2018-01-01 through current.

Fields where maintained and public:

- filing ID
- filing type
- issuer legal name
- issuer state
- filing date
- effective date
- termination/withdrawal date
- SEC accession / Form D identifier where applicable
- exemption or registration category
- security type
- filing status
- public document filename
- public document URL
- Internet Site Operator registration identifier where applicable
- amendment indicator
- source last-updated date

## Explicitly exclude

- investor names
- investor addresses
- investor accreditation documentation
- account data
- subscription agreements containing personal information
- confidential financial schedules
- non-public examination/investigation data

Do not deliver NJBOS Form 12 completed investor certifications.

Preferred format: CSV/XLSX.

Coverage state: `SOURCE_AVAILABLE_BY_REQUEST`.
