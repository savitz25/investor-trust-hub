# NJ-INV-002 public metric contract (internal; publication-gated)

This document is **internal-only**. It does not authorize `/new-jersey` or any public
state page. Filename says "public" because it is the contract a later publication ticket
must obey.

## Core rule

Organize evidence. Do not tell consumers who is "best."

No rankings. No Trust Score. No "most risky firms." No exam-compliance leaderboard.
No crowdfunding performance list.

## Approved internal metrics (when source coverage supports them)

- acquired official Bureau enforcement document count
- enforcement coverage state (`ACQUIRED_PARTIAL_HISTORY` until a complete index exists)
- exam years with a public sample package **or** official announcement
- exam topic families by year (source-attributed)
- current exam deadline from the official sample/landing page
- issuer/exemption **filing class inventory** (forms, not a count of secret filings)
- IAR CE **policy** credits (not individual completion)

## Blocked metrics until an authoritative denominator exists

- enforcement rate per state RIA
- exact CURRENT_NJ_STATE_RIA_FIRMS count
- exam pass/fail rate
- "Passed NJ Examination" firm badge
- Trust Score
- adviser ranking
- crowdfunding legitimacy score

Rounded press language such as "nearly 800" or "nearly 900" is **context only**.
It is not an exact denominator table.

## Semantic firewall

- Annual written examination ≠ licensing exam ≠ firm certification ≠ enforcement.
- General order ≠ adverse evidence against every firm.
- Issuer filing ≠ adviser profile.
- Exemption category ≠ approval or endorsement.
- Filed complaint ≠ final finding.
- Individuals remain internal-only.
