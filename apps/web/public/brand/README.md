# Investor Trust Hub — web brand assets

Official mark rebuilt from the source lockup. Do not add `<title>` inside SVG
files used on HTML pages (that became an extra document title in crawlers).

| File | Use |
| --- | --- |
| `mark.svg` | Favicon / inline-capable icon |
| `logo-horizontal-transparent.svg` / `.png` | Full lockup on light or photo |
| `logo-horizontal-black.png` | Full lockup on a black plate |
| `og-landscape-1200x630.png` | Open Graph / Twitter |
| `profile-square-1200.png` | Social avatar |
| `favicon-16.png` / `favicon-32.png` | Raster favicons |
| `android-chrome-192.png` / `512.png` | PWA |

The header and footer render the mark from `@ith/ui` `BrandMark`, not these files.
The complete production kit (stacked, mono, watermark, full app-icon set) lives
outside the repo in `moch up design/Investor Trust Hub Logo System`.
